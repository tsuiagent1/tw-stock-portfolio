## 🚀 核心功能與戰情模組

1. **四大 KPI 戰情總覽卡片**
   - 即時呈現**總持股市值與投入成本**、**累積未實現損益與總報酬率**、**當日損益與當日漲跌幅**，以及**持股檔數／勝率與 CR3 集中度**。
   - 全面採用台股慣例配色（**紅漲綠跌**），當日漲跌徽章與趨勢圖示隨盤面自動切換。

2. **持股即時風控與紀律通報橫幅**
   - 依各標的 `-10%` 硬性停損價自動判定風險狀態，於頁面頂部即時列出每檔持股的現價、停損線、未實現報酬率與當日漲跌幅。

3. **雙圖表互動視覺化（Chart.js）**
   - **資產配置比例（權重圓餅圖）**：清晰呈現各檔持股佔總市值的比重與圖例。
   - **持股漲跌／報酬排行（橫向長條圖）**：支援一鍵切換「**當日漲跌幅**」與「**累積報酬率**」兩種檢視模式，並自動依數值高低排序。

4. **完整庫存詳細明細表**
   - 逐檔列出標的名稱／代號（含零股標記）、產業領域、持股股數、成本價、當前現價、當日漲跌幅（含每股漲跌與當日損益）、持股市值、權重、未實現損益、報酬率與風控狀態標籤。
   - 表尾彙總當日損益、總成本、總市值與結算未實現損益。

5. **富果 Fugle API 自動化同步與離線備援**
   - 前端優先讀取 `portfolio.json` 最新盤後資料，若無法連線則自動退回內嵌基準資料確保頁面正常顯示。
   - 透過 GitHub Actions 與 `update_fugle.py` 定期抓取最新行情並更新 `portfolio.json`。

## 🛠️ 目錄結構

```text
├── .github/workflows/
│   └── update_portfolio.yml   # GitHub Actions 定期抓取 Fugle 盤後數據之自動化流程
├── index.html                 # 戰情儀表板前端核心（深色玻璃擬態介面 + Chart.js 互動圖表）
├── portfolio.json             # 持股清單、成本均價、停損線與最新行情數據庫
├── update_fugle.py            # 富果 Fugle API 盤後資料自動同步 Python 腳本
├── update_portfolio.yml       # 自動化工作流程設定檔
└── README.md                  # 專案說明與公開入口導航
```

## 📈 使用與操作說明

- **即時瀏覽**：直接點擊 [線上儀表板網址](https://tsuiagent1.github.io/tw-stock-portfolio/) 即可載入最新持股戰情面板。
- **圖表模式切換**：於長條圖右上角點擊「當日漲跌幅」或「累積報酬率」，即可即時切換排序依據。
- **手動同步**：點擊儀表板右上角「🔄 重新整理」按鈕，可即時重新讀取 `portfolio.json` 最新數據。
