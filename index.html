富果 Fugle API 與 GitHub Actions 自動排程架構

崔董您好！關於把 Fugle API 存放在本專案 Repo Secrets 的運作解析：

1. Frank 能否直接讀取 Repo Secrets？
GitHub Secrets 採取「只進不出（Write-Only）」之最高資安防護設計，無論是 Frank（沙盒）、Render 主機還是外部 API，皆無法直接讀出 Secret 明文。

2. 為什麼這樣設定反而是最完美的自動化架構？
因為「定時更新」完全不需要由 Frank 手動讀取！而是由 GitHub Actions 在雲端排程無人值守自動執行：

崔董存入 Secrets: FUGLE_API_KEY ↓ GitHub Actions (Cron 排程，週一至五 14:00 自動觸發) ↓ 虛擬機讀取 secrets.FUGLE_API_KEY 執行 update_fugle.py ↓ 調用富果 REST API 抓取最新股價，重算損益與 portfolio.json ↓ 自動 Commit 並重新發布至 GitHub Pages！(24H 全自動零成本)

3. 崔董 3 步設定 Secrets 指南：
① 進入本 Repo 頁面 ➔ Settings ➔ Secrets and variables ➔ Actions
② 點擊 New repository secret
③ Name 填寫 FUGLE_API_KEY，Secret 貼入您的富果 API Key，點擊 Add secret 即完成！
